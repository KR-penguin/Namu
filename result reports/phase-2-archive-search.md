# A. 무엇을·왜

- 기기에 저장된 일기를 날짜(`YYYY-MM-DD`), 기분, 한 줄 요약으로 즉시 찾는 로컬 검색을 보관함에 추가했다.
- 공백과 대소문자를 정규화하고 여러 검색어는 모두 포함하는 AND 조건으로 적용했다. 저장된 모든 일기 version은 유지하며 검색은 목록 표시만 좁힌다.
- 검색어 지우기, 결과 없음, 초기 로딩, 재시도 가능한 로드 오류, 기존 결과가 있는 상태의 새로고침 오류를 각각 구분했다.

# C. Critical Path

- 검색은 전체 로컬 snapshot에만 적용하며 Gateway나 외부 검색 서비스로 일기 내용을 보내지 않는다.
- 검색 중 repository를 다시 읽어도 현재 검색어를 새 snapshot에 재적용한다. 새로고침 실패 시 이미 불러온 결과를 버리지 않는다.
- 날짜·기분·요약 이외의 본문이나 사진 metadata는 검색 index에 넣지 않았다. 검색 결과 선택은 기존의 검증된 과거 일기 재열람 흐름을 그대로 사용한다.
- 전체 Flutter 테스트 476개와 `flutter analyze`를 통과했다.
